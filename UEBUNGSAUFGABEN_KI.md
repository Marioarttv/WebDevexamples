# 🎯 Übungsaufgaben: Web Development mit KI

**Für die Unterrichtsstunde**
**Differenziert nach Schwierigkeitsgrad**

---

## 📋 Übersicht

Jede Aufgabe hat **3 Schwierigkeitslevel**:
- 🟢 **LEVEL 1:** Anfänger (Grundlagen)
- 🟡 **LEVEL 2:** Fortgeschritten (Mehr Details)
- 🔴 **LEVEL 3:** Profi (Komplex & kreativ)

**Zeitrahmen:** 30-40 Minuten
**Ziel:** Eine funktionierende Webseite mit KI-Hilfe erstellen

---

## 🎮 AUFGABE 1: Gaming-Seite

### 🟢 LEVEL 1: Basis-Version (15-20 Min)

**Aufgabe:**
Erstelle eine einfache Webseite über dein Lieblingsspiel.

**Was die Seite haben muss:**
- [ ] Eine große Überschrift mit dem Spiel-Namen
- [ ] Ein Absatz mit 2-3 Sätzen über das Spiel
- [ ] Eine Liste mit 3 Gründen, warum du das Spiel magst
- [ ] Ein Farbschema (z.B. blau, rot, grün)
- [ ] Mindestens eine Schriftart-Änderung

**Prompt-Hilfe:**
```
Erstelle eine HTML-Seite über [DEIN SPIEL].
Die Seite soll enthalten:
- Eine Überschrift mit dem Spiel-Namen
- Einen Absatz über das Spiel
- Eine Liste mit 3 Gründen, warum ich es mag
- CSS-Styling mit [DEINE FARBE] als Hauptfarbe
```

**Erfolgskriterien:**
✅ Seite öffnet ohne Fehler
✅ Alle Texte sind sichtbar
✅ Farben sind angewendet

---

### 🟡 LEVEL 2: Erweiterte Version (25-30 Min)

**Aufgabe:**
Erstelle eine Gaming-Webseite mit mehreren Abschnitten.

**Was die Seite haben muss:**
- [ ] Header mit Titel
- [ ] 3 Abschnitte (z.B. "Über das Spiel", "Gameplay", "Meine Meinung")
- [ ] Jeder Abschnitt in einer eigenen Box mit Rahmen
- [ ] Eine Navigation (Links zu anderen Seiten - müssen nicht funktionieren)
- [ ] Hover-Effekte bei den Boxen
- [ ] Responsive Design (funktioniert auf Handy)

**Prompt-Vorlage:**
```
Erstelle eine Gaming-Webseite über [SPIEL] mit:
- Einem Header mit Titel
- 3 Abschnitten: "Über das Spiel", "Gameplay", "Meine Meinung"
- Jeder Abschnitt in einer Box mit Schatten und abgerundeten Ecken
- Navigation mit 4 Links
- Hover-Effekt: Boxen werden größer
- Responsive für Handys
Nutze [FARBE] als Hauptfarbe. Nur HTML und CSS.
```

**Erfolgskriterien:**
✅ 3 sichtbare Abschnitte
✅ Hover-Effekte funktionieren
✅ Layout passt sich an kleine Bildschirme an

---

### 🔴 LEVEL 3: Profi-Version (35-40 Min)

**Aufgabe:**
Erstelle eine vollständige Gaming-Webseite mit 2 Seiten.

**Was die Seite haben muss:**
- [ ] **Seite 1 (index.html):** Übersicht
  - Header mit Logo und Navigation
  - Hero-Bereich mit großem Bild
  - 3-4 Game-Cards in einem Grid
  - Footer
- [ ] **Seite 2 (detail.html):** Detail-Ansicht
  - Gleicher Header/Footer
  - Detaillierte Spielbeschreibung
  - Pro/Contra-Liste
  - Bewertungs-Sterne
- [ ] Beide Seiten verlinkt
- [ ] Einheitliches Design
- [ ] Animationen beim Scrollen
- [ ] Modernes Farbschema

**Erweiterte Prompt-Strategie:**

**Prompt 1 - Basis:**
```
Erstelle eine Gaming-Website mit 2 Seiten über [SPIELE].

index.html soll haben:
- Header mit Navigation
- Hero-Bereich mit großem Titel
- Grid mit 4 Game-Cards
- Footer
Nutze modernes Design mit [FARBE1] und [FARBE2].
```

**Prompt 2 - Details:**
```
Erstelle die zweite Seite (detail.html) mit dem gleichen Design.
Sie soll haben:
- Gleicher Header/Footer
- Ausführliche Spielbeschreibung
- Pro/Contra-Liste in zwei Spalten
- 5-Sterne-Bewertung
Beide Seiten sollen verlinkt sein.
```

**Prompt 3 - Polish:**
```
Füge folgende Verbesserungen hinzu:
- Smooth Scroll-Animationen
- Hover-Effekte auf den Cards
- Bessere Typografie mit Google Fonts
- Responsive für alle Geräte
```

**Erfolgskriterien:**
✅ 2 Seiten erstellt und verlinkt
✅ Einheitliches Design
✅ Responsive auf Handy
✅ Mindestens 3 Animationen/Effekte

## ⚽ AUFGABE 2: Sport-Fanpage

### 🟢 LEVEL 1: Basis-Version (15-20 Min)

**Aufgabe:**
Erstelle eine Fanpage für deinen Lieblings-Sportverein oder -Sportler.

**Was die Seite haben muss:**
- [ ] Überschrift mit Namen des Vereins/Sportlers
- [ ] Bild (Platzhalter okay)
- [ ] Info-Box mit 3 Fakten
- [ ] Vereinsfarben im Design
- [ ] Ein "Mehr erfahren"-Button

**Starter-Prompt:**
```
Erstelle eine HTML-Seite für [VEREIN/SPORTLER].
Füge hinzu:
- Große Überschrift
- Platzhalter-Bild (300x300px)
- Info-Box mit 3 Fakten
- Einen Button "Mehr erfahren"
Style mit den Farben [VEREINSFARBE1] und [VEREINSFARBE2].
```

---

### 🟡 LEVEL 2: Erweiterte Version (25-30 Min)

**Aufgabe:**
Erstelle eine Sport-Webseite mit Spieler-Profilen.

**Was die Seite haben muss:**
- [ ] Header mit Vereins-Logo (Platzhalter)
- [ ] 3 Spieler-Karten mit:
  - Foto
  - Name
  - Position
  - Rückennummer
- [ ] Tabelle mit letzten 5 Spielergebnissen
- [ ] Vereinsfarben durchgängig

**Prompt-Idee:**
```
Erstelle eine Sportseite für [VEREIN] mit:
- Header mit Logo
- 3 Spieler-Karten im Grid (Foto, Name, Position, Nummer)
- Tabelle mit 5 Spielen (Gegner, Ergebnis, Datum)
- Vereinsfarben: [FARBE1] und [FARBE2]

Nur HTML und CSS.
```

## 📝 Bewertungs-Checkliste

### Für ALLE Levels:

**Technik (5 Punkte):**
- [ ] Code funktioniert ohne Fehler (2 Pkt)
- [ ] HTML ist strukturiert (1 Pkt)
- [ ] CSS ist angewendet (1 Pkt)
- [ ] Datei korrekt gespeichert (.html) (1 Pkt)

**Design (3 Punkte):**
- [ ] Farben passen zusammen (1 Pkt)
- [ ] Lesbar & übersichtlich (1 Pkt)
- [ ] Elemente sind gut angeordnet (1 Pkt)

**Prompting (2 Punkte):**
- [ ] Gute Prompts genutzt (1 Pkt)
- [ ] Code verstanden & angepasst (1 Pkt)

**Gesamt: 10 Punkte**

## 💡 Tipps für Schüler

### Wenn du nicht weiterkommst:

**1. Starte einfacher**
```
Statt: "Erstelle eine komplette Website..."
Besser: "Erstelle erstmal nur eine Überschrift und einen Absatz"
```

**2. Frag nach Erklärung**
```
"Erkläre mir diesen Code Zeile für Zeile"
```

**3. Teile das Problem auf**
```
Prompt 1: HTML-Struktur
Prompt 2: CSS-Styling
Prompt 3: Responsive machen
```

**4. Nutze Beispiele**
```
"Mach es ähnlich wie [BEKANNTE WEBSITE], aber einfacher"
```

**5. Probiere verschiedene Prompts**
```
Wenn einer nicht funktioniert, versuch's anders zu formulieren
```
