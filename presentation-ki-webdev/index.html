Prompt Engineering

Die Kunst, mit Maschinen zu sprechen.

1. Rolle: Wer soll die AI sein?
"Du bist ein Senior Web Developer..."

2. Kontext: Worum geht es?
"Ich baue eine Portfolio-Seite für Fotografie..."

3. Aufgabe: Was genau soll passieren?
"Erstelle den HTML-Code für eine Galerie..."

4. Constraints: Was ist verboten/erlaubt?
"Nutze nur CSS Grid, kein JavaScript..."
