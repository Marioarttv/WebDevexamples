Die 5 Regeln für gutes Prompting

1

Sei spezifisch

"Erstelle eine Webseite über Gaming" → ❌

"Erstelle eine Gaming-Webseite mit 3 Game-Reviews, einem Header und Footer" → ✅

2

Gib Kontext

Erkläre, was du bereits hast und was du erreichen willst

3

Beschreibe das Design

Farben, Layout, Stil - je genauer, desto besser!

4

Iteriere & verfeinere

Erste Version gut? Jetzt optimieren: "Mach den Header größer und nutze Flexbox"

5

Frag nach Erklärungen

"Erkläre mir, wie dieser CSS-Code funktioniert"

Beispiel: Gute vs Schlechte Prompts

❌ Schlecht

"Mach mir eine Webseite"

  • Keine Details zum Thema
  • Kein Design vorgegeben
  • Keine Struktur definiert

✅ Gut

"Erstelle eine HTML-Seite über Fußball mit:

  • Überschrift 'Meine Lieblings-Bundesliga-Teams'
  • 3 Team-Karten mit Name, Logo-Platzhalter, kurzer Beschreibung
  • CSS mit grün-weißem Farbschema
  • Flexbox für die Team-Karten
  • Kommentare im Code zur Erklärung"

Pro-Tipps für bessere Ergebnisse

💡

Schritt für Schritt

Erst HTML erstellen lassen, dann CSS hinzufügen, dann verfeinern

🔍

Code verstehen

Frag: "Erkläre mir jeden Teil dieses Codes in einfachen Worten"

🎯

Beispiele geben

"Mach es ähnlich wie auf Spotify/Instagram/YouTube"

🔄

Iterieren

Nicht zufrieden? "Mach den Text größer", "Ändere die Farbe zu blau"

🐛

Debugging

Fehler? Kopiere die Fehlermeldung in ChatGPT!

Häufige Probleme & Lösungen

❌ Problem: Seite sieht komisch aus

✅ Lösung:

  • HTML und CSS in separate Dateien?
  • CSS richtig eingebunden? <link rel="stylesheet" href="style.css">
  • Beide Dateien im gleichen Ordner?

❌ Problem: KI macht immer die gleichen Fehler

✅ Lösung:

Neuer Chat! Starte eine frische Konversation mit verbessertem Prompt

❌ Problem: Ich verstehe den Code nicht

✅ Lösung:

Frag nach! "Erkläre mir diesen Code Zeile für Zeile für Anfänger"
