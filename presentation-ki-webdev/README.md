# Web Development mit KI-Tools - Präsentation

Eine interaktive PowerPoint-ähnliche Präsentation als Webseite für den Unterricht zum Thema KI-gestützte Webentwicklung.

## 🎯 Features

- **14 professionell gestaltete Folien** zum Thema Web Development mit KI
- **Vollständige Tastatursteuerung** für flüssige Präsentation
- **Touch-/Swipe-Support** für Tablets und Touchscreens
- **Progress Bar** zeigt Fortschritt durch die Präsentation
- **Responsive Design** funktioniert auf allen Bildschirmgrößen
- **Druckfunktion** für Handouts
- **URL-Hash-Navigation** für direktes Anspringen von Folien
- **Vollbild-Modus** für professionelle Präsentationen

## 🚀 Verwendung

### Präsentation starten

1. Öffne `index.html` in einem modernen Browser (Chrome, Firefox, Safari, Edge)
2. Drücke **F11** oder **Esc** für Vollbildmodus
3. Navigiere mit den Pfeiltasten oder den Buttons unten

### Tastaturkürzel

| Taste | Aktion |
|-------|--------|
| `→` / `↓` / `Leertaste` / `PageDown` | Nächste Folie |
| `←` / `↑` / `PageUp` | Vorherige Folie |
| `Home` | Zur ersten Folie |
| `End` | Zur letzten Folie |
| `Esc` | Vollbild ein/aus |
| `Strg+P` | Drucken |
| `?` | Hilfe anzeigen |

### Navigation mit Buttons

- Nutze die **◀** und **▶** Buttons unten in der Mitte
- Die Anzeige zeigt die aktuelle Foliennummer (z.B. "1 / 14")

### Touch/Mobile

- **Wische nach links** für nächste Folie
- **Wische nach rechts** für vorherige Folie

## 🎨 Anpassungen

### Farben ändern

Die Hauptfarben sind in `style.css` definiert:

```css
/* Primärfarben */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### Folien bearbeiten

1. Öffne `index.html`
2. Jede Folie ist ein `<div class="slide">` Element
3. Bearbeite den HTML-Inhalt nach Bedarf
4. Speichern und Browser neu laden

### Eigene Folien hinzufügen

```html
<div class="slide">
    <div class="slide-content">
        <h1>Deine Überschrift</h1>
        <p>Dein Inhalt...</p>
    </div>
</div>
```

## 💡 Tipps für die Präsentation

1. **Vor dem Unterricht testen** - Einmal durchklicken und Technik prüfen
2. **Vollbild nutzen** (F11 oder Esc-Taste) für professionellen Look
3. **Bei Live-Demo**: ChatGPT in separatem Tab/Fenster öffnen
4. **Interaktive Folien**: Prompt Battle (Folie 8) - Schüler nach vorne holen
5. **Hands-On Phase**: Genug Zeit lassen, durch die Reihen gehen
6. **Für Handouts drucken**: Strg+P drückt alle Folien übersichtlich

## 🔧 Technische Details

- **Reine HTML/CSS/JavaScript** - keine Frameworks oder Libraries benötigt
- **Offline nutzbar** - keine Internetverbindung erforderlich
- **Browser-Kompatibilität**: Moderne Browser (Chrome, Firefox, Safari, Edge)
- **Responsive**: Funktioniert auf Desktop, Tablet und Mobile
- **Barrierearm**: Tastaturnavigation vollständig unterstützt
